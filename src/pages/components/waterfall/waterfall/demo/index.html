🚀 快速开始

1. 复制组件文件

将整个 waterfall 目录复制到你的项目中：

cp -r waterfall/ your-project/src/components/

2. 引入样式

在你的主样式文件中引入瀑布流样式：

@import './waterfall/styles/index.scss';

3. 使用组件

在 Vue 组件中导入并使用：

<template> <Waterfall :columns="2" :column-gap="16"> <WaterfallItem v-for="item in items" :key="item.id" :item="item"> <image :src="item.image" /> </WaterfallItem> </Waterfall> </template> <script setup> import Waterfall from './waterfall/components/waterfall.vue' import WaterfallItem from './waterfall/components/waterfall-item.vue' </script>

4. 配置选项

可以通过配置文件自定义默认参数：

import { setWaterfallConfig } from './waterfall/config' setWaterfallConfig({ columns: 3, columnGap: 20, rowGap: 20 })
